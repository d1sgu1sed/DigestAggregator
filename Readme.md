# Разработка агрегатора новостей с функцией дайджеста.

## Задача:
Необходимо написать сервис, который собирает новости из открытых источников (RSS/API), сохраняет их в БД и позволяет получить краткую сводку за указанный период.
### Требования:
 1. Сбор: Реализовать парсер для 2-х источников новостей (например, RSS ленты). Сбор должен быть автоматическим (планировщик) или по команде.
 2. Хранение: БД (любая). Предусмотреть защиту от дублей (одна новость не должна сохраняться дважды).
 3. Отчетность: Реализовать метод/команду получения сводки.
 • Входные параметры: период (день/неделя).
 • Выход: Список основных событий или краткий текстовый файл.
 4. Будет плюсом:
 • Использование Docker.
 • Наличие юнит-тестов.
 • Использование LLM для генерации красивого описания новостей.
 • Обработка ошибок сети (таймауты, недоступность сайтов).
 • Использование Google Alerts

Стек разработки:

| Задача | Инструмент |
|--------|------------|
|HTTP-запросы|`httpx`|
|Парсинг RSS|`feedparser`|
|События при сбоях в сети|`tenacity`|
|БД|`PostgreSQL + SQLAlchemy`|
|Миграции|`Alembic`|
|Планировщик|`APScheduler`|
|Тесты|`pytest`|
|Контейнеры|`Docker + docker-compose`|
